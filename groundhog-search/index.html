Groundhog Day Prediction Search

Look up any weather-predicting animal and see its prediction history, 1990–2026.

About “track record”: the data records each animal’s call (shadow = six more weeks of winter; no shadow = early spring), not the actual weather, so true accuracy can’t be calculated. “Agreement” shows how often an animal matched the majority call among all animals that year. Source: groundhog-day.com.
